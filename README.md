# 杭电创业联盟 · 工作证在线制作

把原来「人工收集证件照 → 复制进 PPT → 导出图片」的工作证制作流程，改成成员自助完成 + 管理员统一管理的网页工具。

## 成员端（首页）

1. 上传证件照（点击或拖拽），弹出裁剪窗口，可缩放、拖动（比例与工作证照片区一致，约 5:7）；
2. 填写姓名、部门（部门带常用选项提示，可自由输入）；
3. 实时预览工作证正反面；
4. 「提交到创盟服务器」把姓名、部门、照片存入后台；
5. 也可以自行下载高清 PNG（1224 × 1940 px，4 倍清晰度）直接打印。

## 管理端（`/admin`，账号密码 cran / cran）

- 查看所有成员提交的姓名、部门、证件照缩略图；
- 单条导出 / 全员批量导出，格式支持 **PNG / JPG / TIFF**（ZIP 打包，正反面各一张）；
- 导出名单 CSV；
- 删除记录；
- **ZIP 批量导入**：把往年的照片打包导入，规范如下。

### ZIP 批量导入规范

zip 根目录必须包含 `list.csv`（UTF-8，首行表头），照片为 JPG/PNG：

```
list.csv：
姓名,部门,照片
张三,宣传部,张三.jpg
李四,技术部,技术部-李四.png
王五,外联部,          （照片列留空则不导入照片）
```

- 照片文件名需与 list.csv 照片列一致（允许带相对路径）；
- 不写表头时按 `姓名,部门,照片` 顺序解析；
- 省略照片列时自动匹配「姓名.jpg / 姓名.png」；
- 同名同部门视为同一人，新照片覆盖旧照片。

## 卡片样式

复刻自 `工作证_20261013_121340_0000.pptx`，所有装饰素材（蓝色几何条、底部横条、logo、水印、照片占位图）均从该 PPT 中提取。字体回退栈：`楷体/新細明體/宋体` 等系统字体，无需联网加载。

## 技术栈

- 前端：React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui
- 裁剪：`react-easy-crop`；图片导出：`html-to-image` + `utif`（TIFF）+ `jszip`
- 后端：`server/server.cjs`，纯 Node.js 标准库实现，零依赖
  - 数据保存在 `data/`（submissions.json + photos/，位于仓库根目录，已 gitignore）

## 本地开发

```bash
npm install
node server/server.cjs   # 后端，端口 8377
npm run dev              # 前端，http://localhost:3000（/api 已代理到 8377）
```

管理员密码可用环境变量覆盖：`IDCARD_ADMIN_USER` / `IDCARD_ADMIN_PASS`。
