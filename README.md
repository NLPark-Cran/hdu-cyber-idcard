# 杭电创业联盟 · 工作证在线制作

把原来「人工收集证件照 → 复制进 PPT → 导出图片」的工作证制作流程，改成成员自助完成的网页工具：

1. 成员打开网页，上传自己的证件照（点击或拖拽）；
2. 弹出裁剪窗口，可缩放、拖动，裁剪比例与工作证照片区一致（约 5:7）；
3. 填写姓名、部门（部门带常用选项提示，可自由输入）；
4. 实时预览工作证正反面效果；
5. 一键下载高清 PNG（1224 × 1940 px，4 倍清晰度），直接用于打印。

卡片样式复刻自 `工作证_20261013_121340_0000.pptx`，所有装饰素材均从该 PPT 中提取。

## 在线地址

<https://id.hub.tt2.li>

## 技术栈

- React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui
- `react-easy-crop`：照片裁剪（缩放 + 拖动）
- `html-to-image`：客户端导出 4 倍清晰度 PNG

## 本地开发

```bash
npm install
npm run dev        # 默认 http://localhost:3000
npm run build      # 产物在 dist/，纯静态站点
```

## 部署

`dist/` 是纯静态站点，任何静态服务器（nginx 等）指向该目录即可。详见 `DEPLOY.md`。

## 素材说明

`src/assets/` 下的装饰图片（蓝色几何条、底部横条、logo、水印、照片占位图）提取自工作证 PPT 原文件，版权归杭州电子科技大学创业联盟所有，请勿用于其他用途。
